# API для вкладки "Все проекты"

Нужен endpoint для получения всех существующих проектов администратором.

## Рекомендуемый вариант

Использовать существующую авторизацию по токену:

```http
GET /api/calendar/projects/all/
Authorization: Token <admin-token>
```

Доступ должен быть только у администратора/суперадминистратора.

## Альтернативный вариант

Если нужен один запрос, куда передаются логин и пароль администратора:

```http
POST /api/calendar/projects/all/
Content-Type: application/json
```

Тело запроса:

```json
{
  "nickname": "admin",
  "password": "admin-password"
}
```

Backend должен:

- проверить логин и пароль;
- проверить, что пользователь является администратором/суперадминистратором;
- вернуть `401`, если логин или пароль неверные;
- вернуть `403`, если пользователь не админ;
- вернуть `200` и список проектов, если всё успешно.

## Формат ответа

Ответ должен быть массивом проектов:

```json
[
  {
    "id": 1,
    "login": "main-office",
    "title": "Основной проект",
    "name": "Комната офиса",
    "image_url": null,
    "icon": "🚀",
    "tasks_count": 12,
    "progress": 75,
    "creator": 1,
    "creator_nickname": "ivan",
    "members_count": 5,
    "description": "Рабочие задачи отдела",
    "room_created_at": "2026-04-27T10:00:00Z"
  }
]
```

## Обязательные поля для фронта

Для отображения карточек во вкладке `Все проекты` фронту нужны:

- `id` — уникальный идентификатор проекта;
- `title` или `name` или `login` — название проекта;
- `image_url` или `image` — картинка проекта, если есть;
- `icon` — иконка/emoji, если картинки нет;
- `tasks_count` или `task_count` — количество задач в проекте;
- `progress`, `progress_percent`, `completion_percent` или `percent` — процент выполнения от `0` до `100`.

Если у проекта нет задач, нужно вернуть:

```json
{
  "tasks_count": 0,
  "progress": 0
}
```

## Дополнительные поля для будущего

Желательно также возвращать:

- `creator` — id создателя проекта;
- `creator_nickname` — ник создателя;
- `members_count` — количество участников проекта;
- `description` — описание проекта;
- `room_created_at` — дата создания проекта.

## Ошибки

```http
401 Unauthorized
```

Пользователь не авторизован или логин/пароль неверные.

```http
403 Forbidden
```

Пользователь авторизован, но не является администратором.

```http
200 OK
```

Успешный ответ со списком проектов.
